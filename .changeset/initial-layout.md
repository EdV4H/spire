グリッド座標から画面座標への変換。

- 4方向の `orientation`（既定は `bottom-up` = row 0 が下）
- シード付きジッター。ノード id をキーにするので、ノードを足し引きしてもマップ全体の見た目が入れ替わらない。マップの `seed` から導出されるためどこで描いても同じ
- エッジのベジェ経路（SVG path 文字列）

描画は一切しないし、DOM にも触れない。React レンダラと `renderToSVG` が**同一の計算**を共有するために独立したパッケージにしてある — シェア画像が画面と食い違うのは最悪の壊れ方なので。
